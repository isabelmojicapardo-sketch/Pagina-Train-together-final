# Pagina-Train-together-final
Train Together es una plataforma web enfocada en la exploración de una comunidad fitness multidisciplinaria, fue diseñada para conectar usuarios con distintas experiencias de entrenamiento en un entorno visual, dinámico e intuitivo. El proyecto propone una interfaz digital que integra diferentes disciplinas como baile, hyrox, kickboxing, pilates y preparación personalizada, permitiendo navegar por espacios específicos con identidad visual propia. A través del diseño web y la construcción de interfaces, se desarrollo una experiencia centrada en la navegación, el impacto visual y la organización de contenido, utilizando principios de diseño responsivo, jerarquía gráfica y coherencia estética. Ademas de esto, en cada disciplina podemos ver, imagen representativa e información relevante, generando una experiencia diferenciada que fortalece la identidad de la plataforma. El proyecto explora la relación entre estética, interacción y funcionalidad en espacios digitales, integrando herramientas de desarrollo web para construir una propuesta visual contemporánea inspirada en comunidades deportivas y experiencias de entrenamiento inmersivas.
